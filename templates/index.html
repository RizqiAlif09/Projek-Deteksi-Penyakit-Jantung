Tentang aplikasi

Data terstruktur, hasil yang mudah dibaca.

HEAL-M (Heart Disease Early Alert with Machine Learning) merupakan prototipe untuk mendemonstrasikan prediksi kelas penyakit jantung dari parameter klinis terstruktur.

Gunakan halaman prediksi untuk mengisi data, lalu baca hasil model beserta catatan keterbatasannya. Aplikasi ini tidak menyimpan riwayat prediksi.
